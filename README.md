# 🌱 Proyecto Spring Boot + Vaadin + Java 21

Este proyecto combina **Spring Boot 3.3.x**, **Vaadin 24+** y **Java 21**, utilizando **Visual Studio Code** sobre **Ubuntu**.  
El objetivo es crear una aplicación web moderna basada en componentes UI (Vaadin) con el backend de Spring Boot.

---

## 🧩 1️⃣ Instalación de Java 21 con SDKMAN

SDKMAN permite instalar y gestionar múltiples versiones de Java de manera sencilla.

### 🔹 Instalar SDKMAN
```bash
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
